# CEPiK Fleet Intelligence v1

DealerMind получает только статистическое наблюдение регистраций в заданной неделе для выбранной модели в Польше.

- не сохраняются VIN, регистрационные номера, владельцы, адреса или любые первичные записи API;
- в базе остаются только счётчик регистраций и распределения по году выпуска, топливу и воеводству;
- каждый запуск создаёт новый `PolandFleetSnapshot`; изменение и удаление снимков запрещены на уровне модели;
- график означает «регистрации в периоде», а не полный размер автопарка страны.

## Настройка

Производственный CEPiK API используется напрямую; ключи sandbox CPA для этого модуля не нужны. При необходимости переопределите адрес в корневом `.env`:

```env
CEPIK_API_URL=https://api.cepik.gov.pl/v1/pojazdy
```

После перезапуска API откройте `/fleet`, выберите модель и нажмите «Собрать за 30 дней». Первый снимок появится также в её карточке базы знаний.

Источник необходимо отображать как CEPiK. Условия использования и актуальный доступ описаны на официальной [странице API CEPiK](https://www.gov.pl/web/cepik/api-dla-centralnej-ewidencji-pojazdow-i-kiercow-api-do-cepik).
