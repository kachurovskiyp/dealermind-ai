# Vehicle Knowledge Editorial Backlog — Poland Focus

## Definition of done for one model

A model is not considered filled merely because it appears in the focus catalog.
Its reviewed profile must contain:

- exact generation and production period;
- factory engine and gearbox groups, separated by code or power where source permits;
- dealer-facing verdict for each priority configuration, with a mandatory inspection rule;
- model-level defects separated from vehicle-specific inspection risks;
- citations to manufacturer material and at least one independent source;
- explicit limitations where the source does not support a reliability conclusion.

## Source hierarchy

1. Manufacturer repair/VIN data and recalls.
2. Independent roadworthiness and breakdown statistics (ADAC/TÜV where applicable).
3. Polish market observations collected by DealerMind.
4. Trade and specialist sources only as clearly labelled supporting evidence.

No engine receives `recommended`, `caution`, or `avoid` solely from forum sentiment or a generic model reputation.
