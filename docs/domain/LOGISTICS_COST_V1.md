# Logistics Cost v1

## Ubiquitous Language

- **Logistics Profile** — текущая база дилера и тарифы, используемые для новых расчётов.
- **Logistics Snapshot** — неизменяемый результат одного расчёта логистики.
- **Origin** — база, из которой начинается поездка.
- **Destination** — местонахождение автомобиля из объявления.
- **Travelled Distance** — оценочная длина поездки с дорожным коэффициентом и множителем поездки.
- **Cross-border Surcharge** — фиксированная доплата, если автомобиль и база находятся в разных странах.

## Versioned formula

Версия `logistics-v1` использует расстояние по дуге большого круга между координатами,
коэффициент дорожного пути `1.20` и настраиваемый множитель поездки:

```text
travelled_distance = direct_distance × 1.20 × trip_multiplier
distance_cost = travelled_distance × cost_per_km
total_cost = fixed_cost + distance_cost + cross_border_surcharge
```

Множитель `2` означает поездку туда и обратно. Это приближённая оценка, а не маршрут
по дорогам. Координаты населённых пунктов определяются через OpenStreetMap Nominatim и
кэшируются внутри объявления, чтобы повторный расчёт не создавал лишний запрос.

Каждый Logistics Snapshot содержит входные координаты, составляющие стоимости,
версию формулы и объяснение. Снимки append-only. При обновлении логистики DealerMind
вычитает предыдущую логистическую стоимость из общих расходов и добавляет новую,
сохраняя прочие расходы возможности.
